Separate from the Lumina fiducial pipeline. Everything specific to these runs is in this directory and is run **from this
directory** (`cd xray`); the shared pipeline code (`../compute_Jalpha*.c`, `../make_SFR_eff.py`, `../make_Z_snapshots.py`,
